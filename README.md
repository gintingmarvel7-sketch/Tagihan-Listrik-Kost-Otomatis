# Tagihan-Listrik-Kost-Otomatis
Projek Sistem Tagihan Listrik Kos Otomatis (Smart Kos Metering) adalah sistem berbasis Internet of Things (IoT) yang dirancang untuk mengukur konsumsi energi listrik di setiap kamar kos secara real-time, mengonversinya menjadi nominal tagihan rupiah secara otomatis, serta mengatur pemutusan atau penyambungan aliran listrik dari jarak jauh.
